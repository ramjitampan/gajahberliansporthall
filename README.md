# badminpuqi_or_sum

Frontend BadminLap.id — aplikasi booking lapangan badminton berbasis React, Vite, dan JavaScript.

## Menjalankan lokal

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Booking dan pembayaran saat ini menggunakan mock service frontend; belum terhubung ke backend atau payment gateway.
